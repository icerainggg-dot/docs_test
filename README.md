# 문서 동시편집 (HWPX·XLSX)

한글 문서(HWPX/HWP)와 엑셀 문서(XLSX)를 여러 사람이 브라우저에서 동시에 고치는 프로그램입니다.
문서를 올린 사람이 함께 고칠 사람을 지정하며, 지정받은 사람만 그 문서를 열고 고칠 수 있습니다.

```
브라우저 (편집기 + Yjs)  ⇄  동기화 서버 (Hocuspocus, 권한 확인)  →  저장 워커 (HWPX·XLSX 생성)  →  파일 저장소 / WebDAV(Nextcloud)
```

## 실행

Node.js 22.18 이상이 필요합니다. 소스는 TypeScript이며, 서버는 Node가 타입만 지우고 그대로 실행하므로 서버 쪽 빌드 단계가 없습니다.

```bash
npm install
npm run build     # 웹 화면 빌드 (dist/web)
npm start         # http://localhost:8787
```

처음 접속하면 로그인 화면이 나옵니다. 「계정이 없으면 가입하기」로 계정을 만드세요.
시험용 견본은 `samples/`에 있습니다: `시험서식.hwpx`(본문 문단과 2×2 표), `부서예산.xlsx`(서식·병합·수식·시트 두 개).

개발할 때는 `npm run dev` (서버 8787 + Vite 5173).
Docker: `docker build -t hwpx-coedit . && docker run -p 8787:8787 -v hwpx-data:/data hwpx-coedit`

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT`, `HOST` | `8787`, `0.0.0.0` | 서버 주소 |
| `DATA_DIR` | `./data` | 계정·원본·편집 상태·저장본 위치 |
| `SIGNUP` | `open` | `closed`로 두면 스스로 가입할 수 없고, 관리자가 계정을 만듭니다 |
| `COOKIE_SECURE` | 없음 | `1`이면 로그인 쿠키를 HTTPS로만 보냅니다 (HTTPS로 운영할 때 켜세요) |
| `TRUST_PROXY` | 없음 | 역방향 프록시 뒤에서 쓸 때 (예: `1`) — 로그인 시도 제한이 실제 접속 주소로 동작합니다 |
| `WEBDAV_URL`, `WEBDAV_USER`, `WEBDAV_PASSWORD` | 없음 | 지정하면 저장본을 WebDAV 폴더(Nextcloud 등)에도 올림 |

### 계정 관리 (서버 컴퓨터에서)

```bash
node scripts/users.ts add <아이디> <이름> <암호>   # 계정 만들기
node scripts/users.ts passwd <아이디> <새 암호>    # 암호 바꾸기 (그 계정의 로그인은 모두 끊김)
node scripts/users.ts list                          # 계정 목록
```

## 권한

| | 올린 사람 | 편집 권한을 받은 사람 | 그 밖의 사람 |
|---|---|---|---|
| 목록에 보이기, 열기, 고치기, 내려받기 | O | O | X (문서가 없는 것처럼 보임) |
| 함께 고칠 사람 지정·해제 | O | X (누가 참여하는지만 봄) | X |
| 제목 바꾸기, 문서 지우기 | O | X | X |

- 「공유」 버튼에서 이름이나 아이디로 사람을 찾아 「편집 권한 주기」를 누릅니다.
- 권한을 거두면 그 사람이 열어 둔 화면이 즉시 막히고, 그 뒤에 보낸 편집은 반영되지 않습니다.
- 실시간 연결(WebSocket)도 로그인 쿠키로 사람을 확인하고 문서마다 권한을 검사합니다.
- 암호는 scrypt로 감춰 저장하고, 같은 아이디로 15분에 10번 넘게 틀리면 잠시 막습니다. 다른 사이트에서 보낸 요청은 거절합니다.
- 사람 찾기는 로그인한 모든 사람이 쓸 수 있어, 같은 서버의 사용자 이름과 아이디가 서로 보입니다.

## 할 수 있는 것

**한글(HWPX)**
- 본문과 **표 셀** 안의 글자 동시편집 (입력·삭제·문단 나누기/합치기·여러 줄 붙여넣기)
- 굵게·기울임·밑줄·취소선·글자색
- 한글 입력기(IME) 조합 처리 — 조합 중에는 다른 사람의 변경을 미뤘다가 조합이 끝나면 반영

**엑셀(XLSX)**
- 셀 값 동시편집: 숫자·글자·참/거짓·수식 입력, 지우기, 여러 칸 복사·붙여넣기(엑셀과 주고받기 가능)
- 수식 계산 — 고친 값이 다른 셀·다른 시트의 수식에 바로 반영 (함수 280여 개, 시트 간 참조, 정의된 이름)
- 원본의 숫자 서식(#,##0 / % / 날짜 등), 글꼴·색·채우기·테두리·정렬, 병합, 열 너비·행 높이 표시
- 여러 시트(탭), 수식 입력줄, 키보드 이동(방향키·Enter·Tab·Ctrl+방향키·PageUp/Down), F2·두 번 눌러 고치기
- 한글 입력기 조합으로 바로 셀 입력
- 같은 셀을 두 사람이 동시에 고치면 나중 입력이 남습니다 (엑셀 공동편집과 같은 방식)

**공통**
- 다른 참여자의 커서·선택 영역·이름 표시, 실행 취소/다시 실행(내 편집만)
- 자동 저장(편집이 멈추면 파일 생성), 시점별 저장본, 내려받기
- 저장 검사 — 만든 파일을 다시 읽어 편집 내용이 그대로 들어갔는지 매번 확인

## 아직 없는 것

- **엑셀:** 행·열 넣기/지우기, 시트 추가/삭제, 셀 서식 바꾸기(굵게·색·숫자 서식), 열 너비 조절, 틀 고정, 차트·그림 표시
  (차트·피벗·조건부 서식 등은 화면에 안 보일 뿐 원본 그대로 저장됩니다)
- **엑셀:** 지원하지 않는 함수가 든 수식은 원본에 저장되어 있던 값을 보여 주고, 파일을 엑셀로 열 때 다시 계산됩니다
- **한글:** 표 구조 편집(행·열 추가 등), 그림·개체 편집, 표 안의 표, 머리말·꼬리말·각주 편집, 문단 서식, 글꼴·크기 변경
- 보기 전용 권한(지금은 "편집 가능" 한 가지), 조직 계정 연동(Keycloak 등), 부하 시험
- 한컴오피스·엑셀에서 저장본이 제대로 열리는지에 대한 검증 (다른 해석기로 다시 여는 검사만 자동화되어 있음)

표·그림을 품은 한글 문단은 지워지지 않도록 보호됩니다(그 문단 앞에서 Backspace로 합치기 불가).
글꼴은 보는 사람의 컴퓨터에 설치된 것을 쓰므로, 한컴 글꼴이 없으면 줄 나눔이 한글 프로그램과 다를 수 있습니다.

## 동작 원리

- **원본은 그대로 두고 변경만 공유합니다.** 모든 참여자와 저장 워커가 같은 원본 파일에서 출발하고, Yjs 문서에 담긴 변경을 그 위에 맞춥니다.
- **한글:** Yjs 문서(문단 리스트 + 문단별 `Y.Text`)를 `Reconciler`가 rHWP 문서에 맞춥니다. 실시간 편집, 늦게 들어온 참여자, 실행 취소, 저장 워커가 모두 같은 코드를 씁니다.
  글자마다 원본의 글자모양 번호를 들고 다녀, 문단을 나누거나 합쳐도 글꼴·크기가 유지됩니다.
- **엑셀:** 고친 셀만 `Y.Map`("시트번호:주소" → 입력값)에 담습니다. 저장할 때는 원본 XLSX의 시트 XML에서 그 셀만 바꾸고,
  다른 셀이 바뀌어 달라진 수식 결과(캐시 값)를 고친 뒤, 엑셀이 열 때 다시 계산하도록 표시합니다.
  수식 계산은 브라우저와 서버가 같은 코드(`src/shared/xlsx/calc.ts`)를 씁니다.

| 경로 | 내용 |
|---|---|
| `src/shared/model.ts`, `ops.ts`, `reconciler.ts`, `hwp-adapter.ts` | 한글: 데이터 모델, 편집 연산, rHWP 맞추기 |
| `src/shared/xlsx/` | 엑셀: 해석(`parse`), 저장(`write`), 수식 계산(`calc`), 숫자 서식(`format`) |
| `server/index.ts` | REST API, Hocuspocus 동기화·권한 확인, 자동 저장 |
| `server/users.ts`, `server/auth.ts` | 계정·세션, 로그인 API |
| `server/store.ts`, `saver.ts`, `webdav.ts` | 파일 저장소, 저장 워커, WebDAV |
| `web/src/editor/` | 한글 편집기 화면 |
| `web/src/sheet/` | 엑셀 편집기 화면 (보이는 칸만 그리는 격자) |
| `web/src/login.ts`, `home.ts`, `share.ts` | 로그인, 문서 목록, 공유 창 |

## 개발

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 서버(8787)와 Vite 개발 서버(5173)를 함께 실행 |
| `npm run typecheck` | 전체 타입 검사 (서버·공통 코드·시험, 브라우저 코드를 각각 검사) |
| `npm test` | 단위·통합 시험 (무작위 3인 동시편집 수렴, 권한, XLSX 저장 시험 포함) |
| `npm run build && npm run test:e2e` | 브라우저 세 개로 로그인·공유·한글/엑셀 동시편집·권한 회수 (Playwright 필요) |

TypeScript 설정은 두 갈래입니다.
- `tsconfig.node.json`: 서버·공통 코드·시험. Node가 직접 실행하므로 `import`에 `.ts` 확장자를 쓰고, 실행 시 지울 수 없는 문법(`enum`, 생성자 매개변수 속성 등)은 쓰지 않습니다(`erasableSyntaxOnly`).
- `tsconfig.web.json`: 브라우저 편집기. Vite가 묶습니다.

XLSX 저장 시험은 ExcelJS(다른 해석기)로 저장본을 다시 읽어 확인합니다.
시험 문서는 직접 만든 견본입니다. 실제 업무 서식으로의 검증(계획의 0단계)은 아직 하지 않았습니다.
